# Start here

1. Drag the zip into your FaceScore folder and double-click it. You get `~/FaceScore/backend`.
2. Open Terminal and paste:

```
cd ~/FaceScore && claude
```

3. Paste this as your first message to Claude Code:

```
Read backend/CLAUDE.md and work through its task queue in order.
Start with tasks 1 and 2, then tell me what you found before wiring anything.
```

That's it. Claude Code reads `backend/CLAUDE.md` for the full context and rules.
